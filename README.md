# Responsive Portfolio Website - Mezzaluna

This repository contains the source code for **Mezzaluna's** personal portfolio website. Built from scratch using HTML, CSS, and JavaScript, this project features a modern, clean, and fully responsive design across all devices.

## 📌 Features
- **Fully Responsive**: Built using a Mobile-First approach for seamless viewing on desktops, tablets, and phones.
- **Clean & Semantic Code**: Structured using clean HTML5 standards for optimal performance.
- **Modern Styling & Interactivity**: Powered by CSS variables and JavaScript for clean visual effects and smooth scrolling.
- **Cross-Browser Compatibility**: Tested and optimized for all modern browsers.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**
